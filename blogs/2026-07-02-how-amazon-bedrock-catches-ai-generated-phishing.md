This post examines how attackers use generative AI and open-source intelligence to craft phishing emails that evade traditional filters, and presents a multi-stage email analysis framework built on Amazon Bedrock foundation models. The framework evaluates behavioral patterns, contextual anomalies, and communication deviations, using sender baseline tracking, multi-dimensional risk scoring, and continuous feedback loops to improve detection over time.
